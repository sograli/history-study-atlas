# 时光地图｜高中历史学习工作台

交互式时间轴、历史政权地图、文明资料和历史事件。文明资料可按年份、地区查看；历史分期为学习参考，分期终止不代表文化或人群消失。

网站文件位于 `site/`。`history-boundaries.tar.gz` 是历史政权地图的压缩数据；GitHub Actions 在发布时解压到网站目录。疆界来源为 Cliopatria / Seshat Global History Databank，采用 CC BY 4.0；出处及变更说明见压缩包内的 `history-boundaries/ATTRIBUTION.txt`。

项目采用 GitHub Pages 发布；提交到 main 后自动构建。网页与仓库为公开内容。
